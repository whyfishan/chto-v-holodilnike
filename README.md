# Что в холодильнике

Сайт, который подсказывает, что приготовить из продуктов, которые есть дома.

**Открыть сайт:** https://whyfishan.github.io/chto-v-holodilnike/

## Что умеет
- Выбор продуктов из холодильника (71 продукт, поиск по названию).
- Подбор блюд: что можно приготовить прямо сейчас и что получится, если докупить 1–2 продукта.
- Кнопка «Купить в Яндекс Лавке» для недостающих продуктов.
- 60 блюд русской, итальянской и американской кухни (с бургерами и десертами), разбитые по разделам.
- Мини-рецепт, примерное КБЖУ на 100 г и интересный факт к каждому блюду.
- Выбранные продукты запоминаются в браузере.
- Удобно открывать с телефона.

## Из чего сделан
Обычные HTML, CSS и JavaScript, без фреймворков и сервера.
Фотографии блюд — с Викисклада (Wikimedia Commons), под свободными лицензиями.
